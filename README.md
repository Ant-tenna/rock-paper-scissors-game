# (Not) epic rock paper scissors game

This is a mini rock paper scissors game made with c++ featuring one of my OCs

## How to play

You start in the menu, after that you gotta chose Z (for rock) X (for paper) or C for scissors. After chosing your move the cpu choses its hand and reveals it. After pressing enter you get to the win, lose or tie screen. There you can press enter again for playing again or esc to get to the menu. 

AI in this project was used for debugging purposes. Not to generate most of the game
